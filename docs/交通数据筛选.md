# 交通数据筛选

SQLite 模式下，采集结束或可处理的中断后，先按导出开关生成原始快照，再执行当前平台交通筛选。
`ENABLE_TRAFFIC_FILTER` 控制筛选；`SQLITE_EXPORT_EXCEL` 和 `SQLITE_EXPORT_JSONL` 同时控制原始与筛选数据的对应格式导出。

筛选结果位于 `data/{平台}/filtered/时间戳/`，每次生成独立的 `traffic_filtered.db`，原始数据库不会修改。自定义 `SAVE_DATA_PATH` 后，以该目录代替 `data`。

## 相关性规则

标题与正文合并后去 HTML、合并空白。帖子按平台内容标识去重，优先保留最后修改时间较新的一条；知乎同时使用内容 ID 和类型。
默认正文至少 5 字，命中地点路网、车辆人员、交通事件或主题、官方处置四类中的至少一类，并具有明确的道路交通相关信号。保留具体事件、事故合集、交通安全科普、驾驶知识和出行提示，不强制出现具体事件；补充撞车、被撞、电摩等表达。仅出现地点或车辆词不足以保留，仍排除答题、明确模拟游戏及缺少交通语境的内容；“交通大学”不作为交通主题依据。
这是可复核的规则筛选，不代表已验证的分类准确率；需通过人工抽检保留和剔除样本评估误差。
评论仅按相关帖子 ID 关联、按评论 ID 去重并清理 HTML，不套用帖子的正文长度或事件描述规则。

## 热点规则

微博采用黄微、刘熠、许烨婧、孙悦《网络舆情推文的热度测度模型构建》（《图书情报工作》，2019，63(20)：17–25）公式（7）的网络传播力指标：

`H = 0.75 × (0.6250 × 转发数 + 0.2385 × 评论数 + 0.1365 × 点赞数) / (Δt + 2)^1.8`

`Δt = (互动量采集时间 - 发布时间) / 86400`，两个时间戳先统一为秒，最终间隔单位为天。
发布时间取 `create_time`，互动量采集时间取 `last_modify_ts`，支持秒和毫秒时间戳。不使用筛选运行时的当前时间，重复筛选相同输入时分数保持不变。
本指标是论文完整模型中的网络传播力部分，不代表完整复现作者影响力、内容感染力等全部指标，也不是官方热搜分数。

配置 `TRAFFIC_HEAT_WEIGHTS` 按点赞、评论、转发顺序排列；`TRAFFIC_HEAT_RHO` 为比例系数，`TRAFFIC_HEAT_GRAVITY` 为时间衰减指数。
默认在热度有效且大于零的交通相关帖内降序排序，取前 20%（条数向上取整）作为热点候选。同分按帖子 ID 升序排列，严格按数量截取。
该比例是项目候选筛选规则，不是论文规定。候选名单需要人工抽检，不能仅凭相对排名认定真实热点。
`TRAFFIC_MIN_HEAT_SCORE=None` 表示不设置最低分；设置数值后作为额外条件。更换公式后不沿用其他计分体系的阈值。
时间缺失、时间顺序异常或互动量缺失/无法解析时，保留相关帖并标记原因，分数为空，不进入候选；零互动帖不进入候选。
低热度交通相关帖仍保留。该指标以采集时点的累计互动量估计传播力，不等同于最近一小时新增互动，不用于跨平台直接比较。
筛选参数表记录公式、文献、时间口径、权重、系数、比例及各阶段数量。阈值和候选比例需要用实际样本人工抽检调整。

## 输出内容

- `weibo_note`：交通相关帖，增加 `heat_score`、`traffic_dimensions`、`is_hot`、`heat_status`、`heat_age_days`（天）、`heat_observed_at`（秒时间戳）、`heat_rank`。`is_hot` 为热点候选标记。
- `weibo_note_comment`：关联评论。
- `traffic_hot_note`、`traffic_hot_comment`：热点帖子和评论视图。
- `traffic_screening`：所有原始帖的筛选原因，包括重复、缺少 ID、正文过短等。
- `traffic_summary`：参数与数量统计。帖子数量不代表独立事件数量。

Excel 包含相关帖子和评论、热点帖子和评论、筛选记录、筛选参数、导出说明。
启用 JSONL 后，导出交通相关帖子（含 `is_hot` 标记）和关联评论。
筛选已适配七个平台。上述数据表名为微博示例，其他平台保留各自原生表名，并增加 `traffic_text` 和 `heat_model` 等筛选字段。

B站、小红书、抖音将各自的点赞、评论、分享数映射到论文公式，记为 `paper_adapted`，适用性需要另行验证。快手按点赞数、贴吧按回复数、知乎按赞同数加评论数排序，记为 `native_total`，不作时间衰减，不宣称为论文热度模型。互动字段缺失或异常时不填零、不进入候选。各平台候选均单独取前 20%，不能直接比较不同平台分数。

Excel 增加人工抽检表，按热点、相关非热点、相关性剔除三组各抽最多 50 条。`human_related`、`human_hot`、`review_notes` 留给人工填写；自动生成样本不代表已完成准确率验证。

平台字段、参数及存储位置见[多平台采集说明](多平台采集说明.md)。

## 指标依据与适用范围

- [论文全文](https://chinaxiv.org/user/view.htm?filetype=pdf&uuid=c16863d7765f45a2b1f0848046052ac1)与[期刊页面](https://www.lis.ac.cn/CN/abstract/abstract23186.shtml)：DOI `10.13266/j.issn.0252-3116.2019.20.002`。采用第20页公式（7），权重来自该文的层次分析，0.75为该文采用的经验参数，适用效果仍需在本项目数据上验证。
- [微博官方话题指数说明](https://m.s.weibo.com/topic/detailexplain)：话题实时热度依赖近三小时阅读、讨论及原创人数，不能仅凭单帖点赞、评论、转发复算。
- [清博微博传播指数 BCI](https://www.gsdata.cn/site/usage-2)：用于评估账号传播能力，包含发博及原创等周期指标，不等同于单帖热度。
- [微博热搜机制升级公告](https://www.sina.cn/news/detail/5292742458475127.html)：热搜排序综合多个维度，单帖互动分数不能冒充官方热搜分数。

论文指标用于排序，候选比例和可选阈值由本项目配置并通过人工抽检验证。
